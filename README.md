A tiny Python program that writes one out-of-office auto-reply to `/output/entry.txt`: an employee finally spending the leave days they were too busy to take last year — all 23 of them — while HR's questions go, by definition of the message itself, unanswered. The line was picked by drafting fourteen candidates and duelling them pairwise in both orders on the bounty judge's own published criteria — really an out-of-office reply first, then the laugh on the first read, then a message a person would gladly switch on, then freshness, then tightness. The bounty runs blind rounds, so the field was mapped from the titles of all 2,052 submissions received so far: the crowded lanes (a houseplant in charge of the inbox, a cat running it, an auto-reply asking for a raise, replies answered in the order they were ignored) were avoided, and the winner's lane — an absence caused by a backlog of untaken leave, with an HR aftermath — appears nowhere in the field. It beat the strongest sampled lines (a cover named Dave who left in 2019, an auto-reply to be treated as a bug) on plausibility once the laughs were level, and split honestly with the very best (a goldfish with no thumbs, a leave that grows by a day per email). The drafts, the field map and the full duel record are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
